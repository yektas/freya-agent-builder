## Implications for this repo

Keep direct generation as a measurable baseline. A possible experiment is source-grounded requirement extraction, explicit workflow compilation, local persona tests, and bounded repair of demonstrated failures before platform validation. This is a proposed experiment, not a promoted configuration or an implementation commitment.

Use [the experiment template](experiment-template.md) for behavioral changes, compare across tasks, and record regressions before promotion. Preserve original task/tool fields, translate schemas only at the verified platform boundary, and retain a valid fallback if optional evaluation or repair fails. Register only the selected compiled agent so iterations do not create remote duplicates.
